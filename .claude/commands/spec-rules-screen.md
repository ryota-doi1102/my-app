# 画面仕様書規約

画面仕様書を作成・変更する際に参照する規約。

詳細は `docs/rules/spec/screen-spec-rules.md` を参照。

---

## ファイル命名・配置

```
docs/screens/SCR-USER-02/index.md
docs/screens/SCR-USER-04/index.md
```

- ID 体系: `SCR-{リソース}-{連番2桁}`
- リソース区分: `USER` / `AUTH`
- 1ディレクトリ1画面。補足仕様は同一ディレクトリに別ファイルで追加（例: `import.md`）

---

## 必須セクション

| # | セクション | 内容 |
|---|---|---|
| 1 | 基本情報 | ID / パス / 認証 / 概要 |
| 2 | ファイル構成 | 実装ファイルと役割の対応表 |
| 3 | 機能一覧 | F-XX 単位の機能 ID・名称・概要表 |
| 4 | 各機能詳細 | F-XX ごとのサブセクション |
| 5 | 状態管理 | フックが管理する状態の型と説明（なければ省略） |
| 6 | API | 使用する API の Method / Path / 説明（なければ省略） |
| 7 | 遷移元・遷移先 | 種別 / 画面名 / URL |
| 8 | 関連ファイル | ページコンポーネント・フック・APIクライアント等のパス |
| 9 | 関連ドキュメント | API仕様書・テスト仕様書・DB仕様書へのリンク |

## 機能（F-XX）の記載

**機能一覧テーブル:**

```markdown
| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | フォーム | 入力・バリデーション・保存を行う |
| F-02 | 一覧表示 | 検索結果をページングして表示する |
```

**フォームを持つ機能に記載する内容:**

- 項目一覧（入力形式・データ形式・バリデーション・備考）
- バリデーション仕様（スキーマ・タイミング・エラー表示位置）
- ボタン（名称と動作）
- 処理フロー（複雑な場合のみ）

---

## 項目一覧（フォーム）

```markdown
| # | 項目名 | 入力形式 | データ形式 | バリデーション | 備考 |
|---|---|---|---|---|---|
| 1 | 氏名 | テキスト | string | 必須・100文字以下 | |
| 2 | 電話番号 | テキスト | string \| null | ハイフンなし10〜11桁 | 任意 |
```

入力形式の選択肢: テキスト / パスワード / 日付 / セレクトボックス / ラジオボタン / 単一チェックボックス / 複数チェックボックス / ファイルアップロード / テキストエリア / 表示のみ

---

## バリデーション仕様

```markdown
- バリデーションライブラリ: zod + React Hook Form
- バリデーションタイミング: 保存ボタン押下時
- エラーメッセージ表示位置: 各フィールドの直下
- スキーマ定義: `shared/schemas/xxx.ts` の `xxxSchema`

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| 氏名 | 必須項目 | 氏名は必須項目です |
```

---

## 処理フロー（フォーム送信の標準）

```markdown
1. 保存ボタン押下時にバリデーションを実行する
2. エラーがある場合は各フィールドの直下に表示して中断する
3. バリデーション通過後、API リクエストを送信する
4. リクエスト中は全フィールドおよび全ボタンを disabled にする
5. 保存完了後、遷移先へ navigate する
6. 遷移先で Snackbar を表示する
   - `navigate(path, { state: { snackbar: { severity: "success", message: "○○しました" } } })`
7. 失敗時はエラーメッセージをページ上部に表示し、disabled を解除する
```

---

## 状態管理

```markdown
| 状態 | 型 | 説明 |
|---|---|---|
| `isSubmitting` | `boolean` | 送信中フラグ |
| `apiError` | `string \| null` | APIエラーメッセージ |
```

- ローカル変数（`useState` を使わないもの）は記載しない
- React Hook Form が管理するフォーム値は記載しない

---

## 更新ルール

画面・フックを変更したら以下を同時に更新する:
1. `docs/screens/_screen_list.md`
2. 対応するテスト仕様書（`docs/tests/frontend/`）
