# テンプレートファイルダウンロード

## 基本情報

| 項目 | 内容 |
|---|---|
| ID | API-USER-07 |
| メソッド | GET |
| パス | /api/v1/users/template |
| 認証 | JWT必須 |
| 概要 | インポート用CSVテンプレートファイルをダウンロードする |

## リクエスト

リクエストボディなし。クエリパラメータなし。

## レスポンス

### 成功時

| ステータスコード | 説明 |
|---|---|
| 200 | テンプレートファイル（CSV） |

- `Content-Type: text/csv; charset=utf-8`
- `Content-Disposition: attachment; filename="users_import_template.csv"`

ヘッダー行のみの27列CSVファイルを返す。

```
"ID","氏名","メールアドレス","パスワード","電話番号","生年月日","性別","郵便番号","都道府県","市区町村","番地","建物名","希望勤務形態","資格","自己PR","職歴1_会社名","職歴1_開始月","職歴1_終了月","職歴1_役職","職歴2_会社名","職歴2_開始月","職歴2_終了月","職歴2_役職","職歴3_会社名","職歴3_開始月","職歴3_終了月","職歴3_役職"
```

### エラー時

共通エラーコード：docs/api/_status_codes.md を参照。

#### このAPIで発生するエラー

| ステータスコード | code | メッセージ | 説明 |
|---|---|---|---|
| 401 | UNAUTHORIZED | 認証が必要です | 未認証でアクセスした場合 |
| 401 | UNAUTHORIZED | トークンが無効です | トークンが存在しない・無効化済み・期限切れ |
| 500 | INTERNAL_SERVER_ERROR | 予期せぬエラーが発生しました | サーバーエラー |

## 処理フロー

| ID | 処理内容 | ステータスコード | エラーコード | エラーメッセージ | ログ表示内容 |
|---|---|---|---|---|---|
| API-USER-07-F01 | テンプレートダウンロード処理開始 | - | - | - | `[API-USER-07-F01] テンプレートダウンロード処理開始` |
| API-USER-07-F02 | JWT 検証：未認証の場合は即時エラーを返す | 401 | `UNAUTHORIZED` | `認証が必要です` | `[API-USER-07-F02] JWT検証失敗: ${error.message}` |
| API-USER-07-F03 | 27列のヘッダー行のみの CSV を生成し、UTF-8 BOM 付きで 200 を返す | 200 | - | - | `[API-USER-07-F03] テンプレートダウンロード完了` |

## 備考

- 列定義は API-USER-08（インポート）と完全に共通
- UTF-8 BOM 付きCSVとして返すため、Excel で直接開いても文字化けしない
