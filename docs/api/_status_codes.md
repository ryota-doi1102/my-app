## 成功時ステータスコード
| ステータスコード | 説明 |
|---|---|---|
| 200 | 取得・更新成功 |
| 201 | 作成成功 |
| 202 | リクエストを受け付けたが処理はまだ完了していない |
| 204 | 削除成功（bodyなし） |


## エラー時ステータスコード

| ステータスコード | code | 説明 |
|---|---|---|
| 400 | BAD_REQUEST | リクエストの形式が不正・JSONが壊れている |
| 401 | UNAUTHORIZED | 認証エラー |
| 403 | FORBIDDEN | 認可エラー（ログイン済みだが権限なし） |
| 404 | NOT_FOUND | リソースが存在しない |
| 409 | CONFLICT | 重複エラー |
| 422 | VALIDATION_ERROR | バリデーションエラー（形式は正しいが値が不正） |
| 500 | INTERNAL_SERVER_ERROR | サーバーエラー |

```json
{
  "status_code": 500,
  "success": false,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "予期せぬエラーが発生しました"
  }
}
```

## エラーメッセージ一覧

### 共通ルール
- エラーメッセージはこの一覧から使用する
- 一覧にないメッセージは追加してから使用する
- 句読点・文末の「。」は使用しない
- `{データ名}` は実際のフィールド名に置き換える
  （例: `{データ名}` → `メールアドレス`）

### 認証・認可

<!-- 汎用 -->
| code | message | 使用場面 |
|---|---|---|
| UNAUTHORIZED | 認証が必要です | 未認証でアクセスした場合 |
| UNAUTHORIZED | メールアドレスまたはパスワードが正しくありません | サインイン失敗 |
| UNAUTHORIZED | トークンが無効です | トークンが存在しない・無効化済み・期限切れ |
| FORBIDDEN | このリソースへのアクセス権限がありません | 認可エラー |

<!-- API-AUTH-02: サインアップ -->
| code | message | 使用場面 |
|---|---|---|
| UNAUTHORIZED | トークンが無効または期限切れです | サインアップトークンが無効・期限切れ・使用済み |
| CONFLICT | このメールアドレスは既に登録済みです | サインアップ時のメールアドレス重複 |

|---|---|---|

### リソース

| code | message | 使用場面 |
|---|---|---|
| NOT_FOUND | {データ名}が見つかりません | 汎用 |
| NOT_FOUND | ユーザーが見つかりません | ユーザー取得失敗 |
| CONFLICT | メールアドレスが既に登録されています | メールアドレス重複 |

### リクエスト

| code | message | 使用場面 |
|---|---|---|
