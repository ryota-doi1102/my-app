# ユーザーインポート画面

CSVファイルを選択してユーザーを一括インポートする画面。

## 基本情報

| 項目 | 内容 |
|---|---|
| ID | SCR-USER-04 |
| パス | /users/import |
| 認証 | JWT必須 |
| 概要 | CSVファイルを選択してアップロードし、バックグラウンドでユーザーを一括登録・更新する |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.tsx` | ページコンポーネント（UI） |
| `useUserImport.ts` | ファイル選択・アップロード・ポーリング・結果管理のロジック |

## 機能一覧

| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | テンプレートダウンロード | インポート用CSVテンプレートをダウンロードする |
| F-02 | ファイル選択・クライアントバリデーション | CSVファイルを選択し、サイズ・件数を事前検証する |
| F-03 | インポート実行 | ファイルをgzip圧縮してアップロードし、バックグラウンドジョブをポーリングして結果を待つ |
| F-04 | 結果表示 | インポート成功時は件数を、失敗時はエラー一覧を表示する |

---

### F-01 テンプレートダウンロード・フォーマット説明

- 「テンプレートをダウンロード」ボタンからインポート用CSVテンプレートをダウンロードできる
- ファイル形式：CSV（UTF-8 BOM 付き）
- ボタンの下に「インポートフォーマット」としてカラム仕様・バリデーションルールを表示し、ファイル作成前に確認できるようにする

#### ボタン

| ボタン名 | 動作 |
|---|---|
| テンプレートをダウンロード | `GET /api/v1/users/template` を呼び出し、CSVファイルをダウンロードする |

#### インポートフォーマット表示

「テンプレートをダウンロード」ボタンの下に以下のテーブルを常時表示する。

凡例：✓ = 常に必須、✓（新規のみ） = ID 空欄（新規作成）時のみ必須、- = 任意

| 列 | カラム名 | 必須 | 形式・バリデーション |
|---|---|---|---|
| 1 | ID | - | 空欄で新規登録。入力する場合は既存ユーザーの UUID |
| 2 | 氏名 | ✓ | 100文字以下 |
| 3 | メールアドレス | ✓ | メールアドレス形式。他のユーザーと重複不可 |
| 4 | パスワード | ✓（新規のみ） | 8文字以上・大文字/小文字/数字を各1文字以上含む。更新時は無視される |
| 5 | 電話番号 | - | ハイフンなし半角数字・10〜11桁 |
| 6 | 生年月日 | ✓ | YYYY-MM-DD形式・18歳以上60歳未満 |
| 7 | 性別 | ✓ | `男性` / `女性` / `その他` のいずれか |
| 8 | 郵便番号 | - | 半角数字7桁（ハイフンなし） |
| 9 | 都道府県 | - | 50文字以下 |
| 10 | 市区町村 | - | 100文字以下 |
| 11 | 番地 | - | 255文字以下 |
| 12 | 建物名 | - | 255文字以下 |
| 13 | 希望勤務形態 | - | セミコロン区切り（例: `フルタイム;リモート`）。`フルタイム` / `パートタイム` / `リモート` / `フリーランス` のいずれか |
| 14 | 資格 | - | セミコロン区切り。各値は1文字以上 |
| 15 | 自己PR | - | 制限なし |
| 16 | 職歴1（会社名） | ✓ | 255文字以下 |
| 17 | 職歴1（開始月） | ✓ | YYYY-MM形式 |
| 18 | 職歴1（終了月） | - | YYYY-MM形式。空欄は在職中として扱う |
| 19 | 職歴1（役職） | ✓ | 255文字以下 |
| 20 | 職歴2（会社名） | - | 255文字以下 |
| 21 | 職歴2（開始月） | - | YYYY-MM形式。職歴2を入力する場合は必須 |
| 22 | 職歴2（終了月） | - | YYYY-MM形式。空欄は在職中として扱う |
| 23 | 職歴2（役職） | - | 255文字以下。職歴2を入力する場合は必須 |
| 24 | 職歴3（会社名） | - | 255文字以下 |
| 25 | 職歴3（開始月） | - | YYYY-MM形式。職歴3を入力する場合は必須 |
| 26 | 職歴3（終了月） | - | YYYY-MM形式。空欄は在職中として扱う |
| 27 | 職歴3（役職） | - | 255文字以下。職歴3を入力する場合は必須 |

**職歴に関する補足**

- 職歴は連番で入力すること（例: 職歴1と職歴3のみ入力は不可）
- 職歴が複数ある場合、最後の職歴以外の終了月は必須（空欄は在職中を意味するため、複数の在職中は不正）

**ファイル全体に関する制約**

- ファイルサイズ：5MB 以下
- データ行数：500件以下（ヘッダー行を除く）
- ファイル内で ID の重複不可
- ファイル内でメールアドレスの重複不可

---

### F-02 ファイル選択・クライアントバリデーション

- ファイル選択エリア（ドラッグ＆ドロップ または 「ファイルを選択」ボタン）からCSVファイルを選択する
- 選択後、以下のクライアントサイドバリデーションを即時実行する
  - ファイルサイズが 5MB 以下であること
  - ファイル内のデータ行数が 500 件以下であること（ヘッダー行を除く）
- バリデーションエラーはファイル選択エリアの直下にインライン表示する
- バリデーション通過後、選択中のファイル名とサイズを表示する

#### クライアントバリデーションエラーメッセージ

| 条件 | エラーメッセージ |
|---|---|
| ファイルサイズが 5MB 超過 | ファイルサイズが上限（5MB）を超えています |
| データ行数が 500 件超過 | データ行数が上限（500件）を超えています |

---

### F-03 インポート実行

#### 処理フロー

1. 「インポートを実行」ボタン押下時、クライアントバリデーションを再実行する（エラーがあれば中断）
2. `CompressionStream`（gzip）でCSVデータを圧縮する（非対応ブラウザは非圧縮で送信）
3. `POST /api/v1/users/import` にアップロードする
4. レスポンスで取得した `jobId` を使い、`GET /api/v1/users/import-jobs/:jobId` を 2 秒間隔でポーリングする
5. 202 が返る間はポーリングを継続し、処理中インジケーターを表示する
6. 200 が返ったら F-04（成功）へ遷移する
7. 4xx / 5xx が返ったら F-04（失敗）へ遷移する

#### アップロード・ポーリング中の制御

- 「インポートを実行」ボタンおよびファイル選択エリアを disabled にして操作を不可とする
- 処理中インジケーター（スピナー等）を表示する

#### ボタン

| ボタン名 | 動作 |
|---|---|
| インポートを実行 | 処理フローを開始する。ファイル未選択またはクライアントバリデーションエラー時は押下不可（disabled） |
| キャンセル | ユーザー一覧画面（`/users/list`）へ遷移する |

---

### F-04 結果表示

#### 成功時

- 「インポートが完了しました」と新規登録件数・更新件数を表示する
- 「一覧に戻る」ボタンでユーザー一覧画面へ遷移する（Snackbar を表示する）
  - Snackbar の内容: `{ severity: "success", message: "インポートが完了しました（新規 {N}件・更新 {N}件）" }`

#### 失敗時

- エラー種別に応じたメッセージを表示する
  - データ不正（422）：バリデーションエラー一覧を表示する
  - システムエラー（500）：「インポートに失敗しました。しばらく時間をおいて再度お試しください。」を表示する
- 「別のファイルを選択」ボタンで F-02 の初期状態に戻る
- 「一覧に戻る」ボタンでユーザー一覧画面へ遷移する

#### エラー表示形式（422）

| エラー種別 | 表示例 |
|---|---|
| ファイル構造不正 | `ファイル形式が正しくありません（CSVファイルを指定してください）` |
| ヘッダー不一致 | `ヘッダーの形式が正しくありません` |
| データ行なし | `データ行が存在しません` |
| 必須項目未入力 | `{N}行目: 氏名は必須項目です` |
| 形式エラー | `{N}行目: 生年月日の形式が正しくありません（YYYY-MM-DD形式で入力してください）` |
| ID 不一致 | `{N}行目: 指定されたIDが存在しません` |
| メールアドレス重複 | `{N}行目: このメールアドレスはすでに使用されています` |

## 状態管理

| 状態 | 型 | 説明 |
|---|---|---|
| `phase` | `'idle' \| 'file_selected' \| 'uploading' \| 'polling' \| 'completed' \| 'failed'` | 画面フェーズ |
| `file` | `File \| null` | 選択中のファイル |
| `clientError` | `string \| null` | クライアントバリデーションのエラーメッセージ |
| `isDragging` | `boolean` | ドラッグ中フラグ |
| `result` | `{ created: number; updated: number } \| null` | インポート成功時の件数 |
| `serverErrors` | `string[]` | サーバーから返却されたエラーメッセージ一覧 |

## 備考

- `CompressionStream` 非対応ブラウザ（Chrome 80・Firefox 113・Safari 16.4 未満）では非圧縮で送信する
- サーバー側でのCSVフォーマット検証・行単位バリデーション・DB検証はすべてバックグラウンドジョブで実行される（API-USER-09 を参照）
