# サインイン画面

メールアドレスとパスワードを入力してアカウントにサインインする画面。

## 基本情報

| 項目 | 内容 |
|---|---|
| ID | SCR-AUTH-01 |
| パス | /sign-in |
| 認証 | 不要 |
| 概要 | メールアドレスとパスワードを入力してサインインする画面 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `SignInPage.tsx` | ページコンポーネント（UI） |
| `useSignIn.ts` | フォームロジック（RHF + zod） |

## 機能一覧

| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | サインインフォーム | メールアドレス・パスワードを入力してサインインする |
| F-02 | 画面リンク | パスワードリセット画面・サインアップ画面へのリンクを提供する |

---

### F-01 サインインフォーム

#### 項目一覧

| # | 項目名 | 入力形式 | データ形式 | バリデーション | 備考 |
|---|---|---|---|---|---|
| 1 | メールアドレス | テキスト | string | 必須・メール形式・255文字以下 | |
| 2 | パスワード | パスワード | string | 必須・8文字以上・255文字以下 | マスク表示 |

#### バリデーション仕様

- バリデーションライブラリ: zod + React Hook Form
- バリデーションタイミング: サインインボタン押下時（送信時のみ）
- エラーメッセージ表示位置: 各フィールドの直下
- スキーマ定義: `shared/schemas/auth.ts` の `signinSchema`

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| メールアドレス | 必須項目 | メールアドレスを入力してください |
| メールアドレス | メール形式であること | 有効なメールアドレスを入力してください |
| メールアドレス | 255文字以下 | メールアドレスは255文字以内で入力してください |
| パスワード | 必須項目 | パスワードを入力してください |
| パスワード | 8文字以上 | パスワードは8文字以上で入力してください |
| パスワード | 255文字以下 | パスワードは255文字以内で入力してください |

#### ボタン

| ボタン名 | 動作 |
|---|---|
| サインイン | バリデーション後、サインイン処理を実行する |

#### 処理フロー

| ID | 処理内容 | 失敗時処理 | エラーメッセージ | ログ表示内容 |
|---|---|---|---|---|
| F-01-01 | サインイン処理開始 | - | - | - |
| F-01-02 | 全フィールドおよびサインインボタンを disabled にする | - | - | - |
| F-01-03 | `POST /api/v1/auth/signin` にリクエストを送信する | フォームの下部にエラーメッセージを表示し、disabled を解除する | （API エラーメッセージ） | - |
| F-01-04 | レスポンスの `data.accessToken`・`data.refreshToken` が存在することを確認する | フォームの下部にエラーメッセージを表示し、disabled を解除する | サーバーエラーが発生しました | - |
| F-01-05 | `data.accessToken`・`data.refreshToken` をローカルに保存する | - | - | - |
| F-01-06 | ユーザー一覧画面（`/users/list`）へ遷移する | - | - | - |

---

### F-02 画面リンク

| リンク名 | 遷移先 |
|---|---|
| パスワードをお忘れですか？ | パスワードリセット画面（`/reset-password`） |
| サインアップ | サインアップ画面（`/sign-up`） |

## 状態管理

| 状態 | 型 | 説明 |
|---|---|---|
| `error` | `string \| null` | APIエラーメッセージ。失敗時にフォーム下部に表示する |

## API

| Method | Path | 説明 |
|---|---|---|
| POST | `/api/v1/auth/signin` | メールアドレスとパスワードでサインインする |

## 遷移元・遷移先

| 種別 | 画面 | URL |
|---|---|---|
| 遷移元 | サインアップ画面 | `/sign-up` |
| 遷移元 | パスワードリセット画面 | `/reset-password` |
| 遷移先（サインイン成功時） | ユーザー一覧画面 | `/users/list` |
| 遷移先（パスワードリセットリンク） | パスワードリセット画面 | `/reset-password` |
| 遷移先（サインアップリンク） | サインアップ画面 | `/sign-up` |
