# ユーザープロフィール作成画面

新規ユーザーのプロフィール情報を入力・保存する画面。

## 基本情報

| 項目 | 内容 |
|---|---|
| ID | SCR-USER-02 |
| パス | /users/create |
| 認証 | JWT必須 |
| 概要 | 新規ユーザーのプロフィール情報を入力・保存する画面 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.tsx` | ページコンポーネント（UI） |
| `useUserCreateForm.ts` | フォームロジック（RHF + zod） |

## 機能一覧

| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | プロフィール入力フォーム | 18項目のプロフィール情報を入力するフォームを提供する |
| F-02 | 年齢の自動計算 | 生年月日の入力をトリガーに満年齢を即時計算して表示する |
| F-03 | 保存処理 | バリデーション通過後にAPIへリクエストを送信し、成功時に一覧画面へ遷移する |
| F-04 | キャンセル処理 | 入力がある場合は確認ダイアログを表示したうえで一覧画面へ遷移する |

#### 選択肢の取得元

性別・希望勤務形態の選択肢は API から取得せず、`shared/schemas/user.ts` に定義された定数を直接 import して使用する。

| フィールド | import 元 | 値 |
|---|---|---|
| 性別 | `z.enum(['男性', '女性', 'その他'])` の enum 値 | 男性 / 女性 / その他 |
| 希望勤務形態 | `WORK_TYPES` | フルタイム / パートタイム / リモート / フリーランス |

```ts
import { WORK_TYPES } from '@shared/schemas/user'
// gender の選択肢は ['男性', '女性', 'その他'] をリテラルで使用
```

> enum 値は DB スキーマ（`DB-MASTER-01` / `DB-MASTER-02`）と `shared/schemas/user.ts` で同一の値を管理している。選択肢を変更する場合は両方を合わせて修正すること。

### F-02 年齢の自動計算

- 生年月日が入力されると即時に年齢を計算して表示する
- 今日の日付を基準に満年齢を算出する
- 生年月日が未入力の場合は空欄とする
- 年齢フィールドはテキスト表示のみで編集不可

### F-03 保存処理

#### ボタン

| ボタン名 | 動作 |
|---|---|
| 保存 | バリデーション後、保存処理を実行する |

#### プロフィール画像の送信ルール

| フォーム値 | API ペイロード | バックエンドの動作 |
|---|---|---|
| 新規 `File`（ファイル選択あり） | base64 文字列として送信 | 画像を保存する |
| `undefined`（未選択・初期状態） | 省略 | 画像なしで登録する |
| `null`（削除ボタン押下後） | `null` として送信 | 画像なしで登録する |

> 削除ボタンは画像を選択した後に表示される。押下すると選択がキャンセルされ `null` がセットされる。

#### 処理フロー

1. 保存ボタン押下時にバリデーションを実行する
2. バリデーションエラーがある場合はエラーメッセージを各フィールドに表示し、処理を中断する
3. バリデーション通過後、API リクエストを送信する（`PUT /api/v1/users`）
4. リクエスト中は **全フィールドおよび全ボタンを disabled 状態** にして操作を不可とする
5. 保存完了後、ユーザー一覧画面（`/users/list`）へ遷移する
6. 遷移先で Snackbar を表示する（表示内容は画面遷移時の State で渡す）
   - `{ severity: "success", message: "プロフィールを保存しました" }`
7. 保存失敗時はエラーメッセージをページ上部に表示し、disabled を解除して再入力を促す

### F-04 キャンセル処理

#### ボタン

| ボタン名 | 動作 |
|---|---|
| キャンセル | ユーザー一覧画面へ遷移する（入力がある場合は確認ダイアログを表示） |

#### 処理フロー

- いずれかの項目に入力がある場合、確認ダイアログを表示する
  - ダイアログ内容: 「入力内容が失われますが、よろしいですか？」
  - 「OK」押下 → ユーザー一覧画面（`/users/list`）へ遷移
  - 「キャンセル」押下 → ダイアログを閉じて入力を継続
- 全項目が未入力の場合は確認なしにユーザー一覧画面へ遷移する

> **注意**: ブラウザの戻るボタン・リロード・タブ閉じ等のブラウザネイティブ操作には確認ダイアログを表示しない（`beforeunload` 等は使用しない）

## 遷移元・遷移先

| 種別 | 画面 | URL |
|---|---|---|
| 遷移元 | ユーザー一覧画面 | `/users/list` |
| 遷移先（保存成功時） | ユーザー一覧画面 | `/users/list` |
| 遷移先（キャンセル時） | ユーザー一覧画面 | `/users/list` |

## State（画面遷移時に渡すデータ）

```ts
type NavigateState = {
  snackbar: {
    severity: 'success' | 'error' | 'info' | 'warning';
    message: string;
  };
};
```
