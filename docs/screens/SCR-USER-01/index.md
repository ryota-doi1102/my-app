# ユーザー一覧画面

ユーザーの検索・一覧表示・削除・インポート・エクスポートを行う画面。

## 基本情報

| 項目 | 内容 |
|---|---|
| ID | SCR-USER-01 |
| パス | /users/list |
| 認証 | JWT必須 |
| 概要 | ユーザーの検索・一覧表示・削除・インポート・エクスポートを行う画面 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.tsx` | ページコンポーネント（UI） |
| `useUserList.ts` | 一覧・検索・選択・削除・インポート・エクスポートのロジック |

## 機能一覧

| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | 検索・表示 | キーワードと絞り込み条件でユーザーを検索し、ソート・ページングを加えて一覧表示する |
| F-02 | 検索条件の保持 | 別画面から戻った際も検索条件・ソート・ページ・表示件数を復元する |
| F-03 | 一括削除 | チェックボックスで選択したユーザーを確認ダイアログを経て一括削除する |
| F-04 | テンプレートダウンロード | インポート用CSVテンプレートをダウンロードする |
| F-05 | インポート | CSVファイルからユーザーを一括登録する |
| F-06 | エクスポート | 現在の検索条件に一致する全ユーザーをCSV形式でダウンロードする |

---

### F-01 検索・表示

#### 検索条件

| 項目 | 入力形式 | 備考 |
|---|---|---|
| 氏名 | テキスト | 部分一致 |
| メールアドレス | テキスト | 部分一致 |
| 電話番号 | テキスト | 部分一致 |
| 希望勤務形態 | チェックボックス（複数選択可） | いずれかに一致するユーザーを抽出（OR検索） |

#### ソート

以下の項目で昇順 / 降順を切り替えられる。

- 氏名
- メールアドレス
- 電話番号

#### 表示件数

1ページあたりの表示件数をセレクトボックスで選択できる。

- 10件
- 20件
- 50件
- 100件

#### ページング

- ページ番号・前後ページへの移動ができる
- 総件数・現在のページ範囲を表示する（例: 1〜10件 / 全53件）

#### ボタン

| ボタン | 動作 |
|---|---|
| 検索 | 入力中の検索条件で検索を実行し、1ページ目を表示する |
| クリア | 検索条件の入力値をすべて初期化する（検索は実行しない） |

---

### F-02 検索条件の保持

- ユーザー詳細画面など別画面へ遷移し、ユーザー一覧画面に戻った際も検索条件・ソート・ページ・表示件数を保持する
- 保持対象の状態は以下のとおり
  - 検索条件（氏名・メールアドレス・電話番号・希望勤務形態）
  - ソートキー・ソート方向
  - 現在ページ
  - 表示件数
- 保持方法: `localStorage` に状態を保存する
  - 画面マウント時に `localStorage` から状態を復元し、フォームと一覧に反映する
  - `localStorage` の更新タイミングは検索処理実行時（検索ボタン押下・ページ切り替え・ソート変更・表示件数切り替え）
  - クリアボタン押下時はフォームの入力値のみリセットし、`localStorage` の保存値は変更しない
- 破棄条件: 以下のタイミングで `localStorage` の保存値を削除する
  - ログイン成功時
  - ログアウト時
  - 認証失敗時（401 エラーによる自動サインアウト）
- キー名: `userListSearchState`

---

### F-03 一括削除

- 一覧の各行にチェックボックスを表示する
- ヘッダー行のチェックボックスで現在ページの全件を一括選択 / 解除できる
- 1件以上選択されている場合に「削除」ボタンを活性化する
- 削除ボタン押下で確認ダイアログを表示する
  - ダイアログには選択件数を表示する（例: 「3件のユーザーを削除しますか？」）
  - 「削除する」で削除実行、「キャンセル」で閉じる
- 削除後は一覧を再取得して表示を更新する

---

### F-04 テンプレートダウンロード

- 「テンプレートをダウンロード」リンクからインポート用CSVテンプレートをダウンロードできる
- ファイル形式：CSV（UTF-8 BOM 付き）
- カラム構成は [import.md](./import.md) の「CSVフォーマット」を参照

---

### F-05 インポート

- 「インポート」ボタンからCSVファイルを選択してアップロードできる
- ファイル形式：CSV（UTF-8 BOM 付き）、最大 5MB・500 件
- 新規登録と更新を 1 ファイルで混在させることができる（ID 欄で判別）
- アップロード前にブラウザ側で gzip 圧縮してから送信する

詳細仕様は [import.md](./import.md) を参照。

---

### F-06 エクスポート

- 「エクスポート」ボタンで、現在の検索条件に一致する全ユーザーをCSV形式でダウンロードする
- ファイル形式：CSV（UTF-8 BOM 付き）
- ページングに関わらず、検索条件に一致する全件を出力する
- CSVのカラム構成はインポートテンプレートと同一とする
- ID 列には各ユーザーの UUID を出力する
- パスワード列はセキュリティ上の理由から値を出力しない（列は存在するが空欄）
- 職歴が 4 件以上のユーザーは職歴1〜3 のみを出力し、4 件目以降は省略する

## 状態管理

| 状態 | 型 | 説明 |
|---|---|---|
| `searchParams` | オブジェクト | 検索フォームの入力値 |
| `appliedParams` | オブジェクト | 実際に検索に使用されたパラメータ（検索ボタン押下時に確定） |
| `sortKey` | `"name" \| "email" \| "phone" \| null` | ソート対象カラム |
| `sortOrder` | `"asc" \| "desc"` | ソート方向 |
| `page` | `number` | 現在ページ（1始まり） |
| `perPage` | `10 \| 20 \| 50 \| 100` | 1ページあたり件数 |
| `selectedIds` | `string[]` | 削除対象として選択中のユーザーID |
| `deleteDialogOpen` | `boolean` | 削除確認ダイアログの開閉 |

## API

| Method | Path | 説明 |
|---|---|---|
| POST | `/api/v1/users` | 一覧取得（検索・ソート・ページングパラメータ付き） |
| DELETE | `/api/v1/users/bulk` | 複数ユーザー削除（IDリストをボディに渡す） |
| POST | `/api/v1/users/import` | CSVインポートジョブの起動 |
| GET | `/api/v1/users/template` | インポート用テンプレートDL |
| POST | `/api/v1/users/export` | CSVエクスポートジョブの起動（検索条件付き） |
