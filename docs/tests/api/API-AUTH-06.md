# テスト仕様書 - API-AUTH-06 パスワードリセットトークン発行

## 対象API

| 項目 | 内容 |
|---|---|
| ID | API-AUTH-06 |
| メソッド | POST |
| パス | /api/v1/auth/password-reset/request |
| 認証 | 不要 |
| 成功時レスポンス | 201 Created（`token` を含む JSON） |

## テストケース一覧

### 認証系（001〜099）

このAPIは認証不要のため、JWTによる認証チェックは行わない。

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-001 | 有効な Bearer トークンを付与しても正常にリクエストを送信できる（認証ヘッダーは無視される） | 201 Created |

---

### リクエストチェック（クエリ）（100〜199）

このAPIにはクエリパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（パラム）（200〜299）

このAPIにはURLパスパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（ボディ）（300〜399）

#### email（メールアドレス）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-301 | `email` を省略する | 422 / VALIDATION_ERROR / メールアドレスを入力してください |
| TC-302 | `email` に `null` を指定する | 422 / VALIDATION_ERROR |
| TC-303 | `email` に空文字 `""` を指定する | 422 / VALIDATION_ERROR / メールアドレスを入力してください |
| TC-304 | `email` にメールアドレス形式でない文字列（例: `"not-an-email"`）を指定する | 422 / VALIDATION_ERROR / 有効なメールアドレスを入力してください |
| TC-305 | `email` に256文字の文字列を指定する | 422 / VALIDATION_ERROR / メールアドレスは255文字以内で入力してください |

#### リクエストボディ全体

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-374 | リクエストボディを送信しない（空リクエスト） | 400 / BAD_REQUEST / リクエストの形式が正しくありません |
| TC-375 | Content-Type が `application/json` でないリクエストを送信する | 400 / BAD_REQUEST / リクエストの形式が正しくありません |

---

### 分岐処理（400〜499）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-401 | 登録済みユーザーの有効なメールアドレスを指定してリクエストを送信する | 201（`token` が UUID v4 形式で返る） |
| TC-402 | 存在しないメールアドレスを指定する | 404 / NOT_FOUND / このメールアドレスのユーザーが見つかりません |
| TC-403 | 同一メールアドレスで再度リクエストを送信する（古いトークンが無効化され新しいトークンが発行される） | 201（新しい `token` が返る） |

---

### エラー（500〜599）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-501 | DB 接続失敗時にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR（メッセージは実行環境依存のため検証しない） |
| TC-502 | トランザクション内で DB エラーが発生した場合にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR / サーバーエラーが発生しました |
| TC-503 | `NODE_ENV=production` 時に 500 エラーが発生した場合、スタックトレースがレスポンスに含まれないことを確認する | 500 / INTERNAL_SERVER_ERROR / `stack` キーが存在しない |
