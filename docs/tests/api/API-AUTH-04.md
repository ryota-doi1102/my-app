# テスト仕様書 - API-AUTH-04 トークンリフレッシュ

## 対象API

| 項目 | 内容 |
|---|---|
| ID | API-AUTH-04 |
| メソッド | POST |
| パス | /api/v1/auth/refresh |
| 認証 | 不要（refreshToken による独自認証） |
| 成功時レスポンス | 200 OK（新しい `accessToken` / `refreshToken` を含む JSON） |

## テストケース一覧

### 認証系（001〜099）

このAPIは JWT 認証不要のため、Authorization ヘッダーによる認証チェックは行わない。認証は `refreshToken` フィールドの有効性確認で行う。

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-001 | 有効な Bearer トークンを付与しても正常にリクエストを送信できる（Authorization ヘッダーは無視される） | 200 OK |

---

### リクエストチェック（クエリ）（100〜199）

このAPIにはクエリパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（パラム）（200〜299）

このAPIにはURLパスパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（ボディ）（300〜399）

#### refreshToken（リフレッシュトークン）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-301 | `refreshToken` を省略する | 422 / VALIDATION_ERROR / リフレッシュトークンを入力してください |
| TC-302 | `refreshToken` に `null` を指定する | 422 / VALIDATION_ERROR |
| TC-303 | `refreshToken` に空文字 `""` を指定する | 422 / VALIDATION_ERROR / リフレッシュトークンを入力してください |
| TC-304 | `refreshToken` に UUID v4 形式でない文字列（例: `"not-a-uuid"`）を指定する | 422 / VALIDATION_ERROR / UUID v4形式で入力してください |
| TC-305 | `refreshToken` に256文字の文字列を指定する | 422 / VALIDATION_ERROR / リフレッシュトークンは255文字以内で入力してください |

#### リクエストボディ全体

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-374 | リクエストボディを送信しない（空リクエスト） | 400 / BAD_REQUEST / リクエストの形式が正しくありません |
| TC-375 | Content-Type が `application/json` でないリクエストを送信する | 400 / BAD_REQUEST / リクエストの形式が正しくありません |

---

### 分岐処理（400〜499）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-401 | 有効なリフレッシュトークンを指定してリクエストを送信する | 200（新しい `accessToken` と `refreshToken` が返る） |
| TC-402 | 存在しないリフレッシュトークンを指定する | 401 / UNAUTHORIZED / リフレッシュトークンが無効または期限切れです |
| TC-403 | 無効化済み（revoked）のリフレッシュトークンを指定する | 401 / UNAUTHORIZED / リフレッシュトークンが無効または期限切れです |
| TC-404 | 有効期限切れのリフレッシュトークンを指定する | 401 / UNAUTHORIZED / リフレッシュトークンが無効または期限切れです |

---

### エラー（500〜599）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-501 | DB 接続失敗時にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR（メッセージは実行環境依存のため検証しない） |
| TC-502 | トランザクション内で DB エラーが発生した場合にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR / サーバーエラーが発生しました |
| TC-503 | `NODE_ENV=production` 時に 500 エラーが発生した場合、スタックトレースがレスポンスに含まれないことを確認する | 500 / INTERNAL_SERVER_ERROR / `stack` キーが存在しない |
