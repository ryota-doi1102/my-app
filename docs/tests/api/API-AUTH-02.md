# テスト仕様書 - API-AUTH-02 サインアップ

## 対象API

| 項目 | 内容 |
|---|---|
| ID | API-AUTH-02 |
| メソッド | POST |
| パス | /api/v1/auth/signup |
| 認証 | 不要 |
| 成功時レスポンス | 201 Created（`accessToken` を含む JSON） |

## テストケース一覧

### 認証系（001〜099）

このAPIは認証不要のため、JWTによる認証チェックは行わない。

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-001 | 有効な Bearer トークンを付与しても正常にリクエストを送信できる（認証ヘッダーは無視される） | 201 Created |

---

### リクエストチェック（クエリ）（100〜199）

このAPIにはクエリパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（パラム）（200〜299）

このAPIにはURLパスパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（ボディ）（300〜399）

#### token（サインアップトークン）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-301 | `token` を省略する | 422 / VALIDATION_ERROR / トークンを入力してください |
| TC-302 | `token` に `null` を指定する | 422 / VALIDATION_ERROR |
| TC-303 | `token` に空文字 `""` を指定する | 422 / VALIDATION_ERROR / トークンを入力してください |
| TC-304 | `token` に UUID v4 形式でない文字列（例: `"not-a-uuid"`）を指定する | 422 / VALIDATION_ERROR / UUID v4形式で入力してください |
| TC-305 | `token` に256文字の文字列を指定する | 422 / VALIDATION_ERROR / トークンは255文字以内で入力してください |

#### email（メールアドレス）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-306 | `email` を省略する | 422 / VALIDATION_ERROR / メールアドレスを入力してください |
| TC-307 | `email` にメールアドレス形式でない文字列（例: `"not-an-email"`）を指定する | 422 / VALIDATION_ERROR / 有効なメールアドレスを入力してください |
| TC-308 | `email` に256文字の文字列を指定する | 422 / VALIDATION_ERROR / メールアドレスは255文字以内で入力してください |

#### password（パスワード）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-309 | `password` を省略する | 422 / VALIDATION_ERROR / パスワードを入力してください |
| TC-310 | `password` に7文字の文字列を指定する | 422 / VALIDATION_ERROR / パスワードは8文字以上で入力してください |
| TC-311 | `password` に256文字の文字列を指定する | 422 / VALIDATION_ERROR / パスワードは255文字以内で入力してください |
| TC-312 | `password` に大文字を含まない文字列（例: `"password1"`）を指定する | 422 / VALIDATION_ERROR / 半角英数字（大文字・小文字・数字をそれぞれ1文字以上含む）で入力してください |
| TC-313 | `password` に小文字を含まない文字列（例: `"PASSWORD1"`）を指定する | 422 / VALIDATION_ERROR / 半角英数字（大文字・小文字・数字をそれぞれ1文字以上含む）で入力してください |
| TC-314 | `password` に数字を含まない文字列（例: `"Password"`）を指定する | 422 / VALIDATION_ERROR / 半角英数字（大文字・小文字・数字をそれぞれ1文字以上含む）で入力してください |

#### リクエストボディ全体

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-374 | リクエストボディを送信しない（空リクエスト） | 400 / BAD_REQUEST / リクエストの形式が正しくありません |
| TC-375 | Content-Type が `application/json` でないリクエストを送信する | 400 / BAD_REQUEST / リクエストの形式が正しくありません |

---

### 分岐処理（400〜499）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-401 | 有効なトークン・メールアドレス・パスワードを指定してリクエストを送信する | 201（`accessToken` が返る） |
| TC-402 | 存在しないトークンを指定する | 401 / UNAUTHORIZED / トークンが無効または期限切れです |
| TC-403 | 有効期限切れのトークンを指定する | 401 / UNAUTHORIZED / トークンが無効または期限切れです |
| TC-404 | 使用済みのトークンを指定する | 401 / UNAUTHORIZED / トークンが無効または期限切れです |
| TC-405 | トークン発行時のメールアドレスと異なるメールアドレスを指定する | 401 / UNAUTHORIZED / トークンが無効または期限切れです |
| TC-406 | 既に登録済みのメールアドレスを指定する | 409 / CONFLICT / このメールアドレスは既に登録済みです |

---

### エラー（500〜599）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-501 | DB 接続失敗時にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR（メッセージは実行環境依存のため検証しない） |
| TC-502 | トランザクション内で DB エラーが発生した場合にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR / サーバーエラーが発生しました |
| TC-503 | `NODE_ENV=production` 時に 500 エラーが発生した場合、スタックトレースがレスポンスに含まれないことを確認する | 500 / INTERNAL_SERVER_ERROR / `stack` キーが存在しない |
