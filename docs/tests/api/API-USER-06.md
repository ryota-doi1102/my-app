# テスト仕様書 - API-USER-06 ユーザープロフィール一括削除

## 対象API

| 項目 | 内容 |
|---|---|
| ID | API-USER-06 |
| メソッド | DELETE |
| パス | /api/v1/users/bulk |
| 認証 | JWT必須 |
| 成功時レスポンス | 204 No Content（レスポンスボディなし） |

## テストケース一覧

### 認証系（001〜099）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-001 | Authorizationヘッダーなしで最小有効なリクエストを送信する | 401 / UNAUTHORIZED / 認証が必要です |
| TC-002 | 不正な形式のトークン（`Bearer invalid_token`）を付与してリクエストを送信する | 401 / UNAUTHORIZED / トークンが無効です |
| TC-003 | 期限切れのトークンを付与してリクエストを送信する | 401 / UNAUTHORIZED / トークンが無効です |

---

### リクエストチェック（クエリ）（100〜199）

このAPIにはクエリパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（パラム）（200〜299）

このAPIにはURLパスパラメータが存在しないため、該当するテストケースはない。

---

### リクエストチェック（ボディ）（300〜399）

#### ids（削除対象IDリスト）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-301 | `ids` を省略する | 422 / VALIDATION_ERROR / IDは1件以上指定してください |
| TC-302 | `ids` に `null` を指定する | 422 / VALIDATION_ERROR |
| TC-303 | `ids` に空配列 `[]` を指定する | 422 / VALIDATION_ERROR / IDは1件以上指定してください |
| TC-304 | `ids` に101件指定する | 422 / VALIDATION_ERROR / IDは100件以内で指定してください |
| TC-305 | `ids` に UUID 形式でない要素（例: `"abc"`）を含む | 422 / VALIDATION_ERROR / IDの形式が正しくありません |

#### リクエストボディ全体

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-374 | リクエストボディを送信しない（空リクエスト） | 400 / BAD_REQUEST / リクエストの形式が正しくありません |
| TC-375 | Content-Typeが `application/json` でないリクエストを送信する | 400 / BAD_REQUEST / リクエストの形式が正しくありません |

---

### 分岐処理（400〜499）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-401 | 有効なUUIDを1件指定する | 204 No Content |
| TC-402 | 有効なUUIDを複数件（例: 3件）指定する | 204 No Content |
| TC-403 | 有効なUUIDを100件指定する（上限） | 204 No Content |
| TC-404 | 存在しないUUIDのみ指定する（スキップされる） | 204 No Content |
| TC-405 | 論理削除済みのUUIDのみ指定する（スキップされる） | 204 No Content |
| TC-406 | 有効なUUIDと存在しないUUIDを混在させる | 204 No Content（有効なIDのみ削除される） |

### エラー（500〜599）

| テストケースID | テスト内容 | 期待するテスト結果 |
|---|---|---|
| TC-501 | DB接続失敗時にリクエストを送信する | 500 / INTERNAL_SERVER_ERROR（メッセージは実行環境依存のため検証しない） |
