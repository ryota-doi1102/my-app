# 画面仕様書規約

## 概要

- 配置場所: `docs/screens/{SCR-ID}/index.md` に画面単位で管理する
- 画面・フックを変更したら対応する仕様書も合わせて更新する

---

## ファイル命名・ID体系

| 要素 | 形式 | 例 |
|---|---|---|
| ディレクトリ | `docs/screens/SCR-{リソース}-{連番2桁}/` | `docs/screens/SCR-USER-02/` |
| ファイル名 | `index.md` | - |
| 画面 ID | `SCR-{リソース}-{連番2桁}` | `SCR-USER-02` |
| リソース区分 | `USER` / `AUTH` | - |

複数ページに分かれる補足仕様（インポートフォーマット等）は同一ディレクトリに別ファイルで追加する（例: `import.md`）。

---

## 必須セクション

各画面仕様書に以下のセクションを必ず設ける。

| # | セクション | 内容 |
|---|---|---|
| 1 | 基本情報 | ID / パス / 認証 / 概要 |
| 2 | ファイル構成 | 実装ファイルと役割の対応表 |
| 3 | 機能一覧 | F-XX 単位の機能 ID・名称・概要表 |
| 4 | 各機能詳細 | F-XX ごとのサブセクション |
| 5 | 状態管理 | フックが管理する状態の型と説明（状態がない場合は省略） |
| 6 | API | 使用する API の Method / Path / 説明（API がない場合は省略） |
| 7 | 遷移元・遷移先 | 種別 / 画面名 / URL |
| 8 | 関連ファイル | ページコンポーネント・フック・APIクライアント等のパス |
| 9 | 関連ドキュメント | API仕様書・テスト仕様書・DB仕様書へのリンク |

---

## 機能（F-XX）の記載

機能一覧は以下の形式で列挙する。

| ID | 機能名 | 機能概要 |
|---|---|---|
| F-01 | フォーム | 入力・バリデーション・保存を行う |
| F-02 | 一覧表示 | 検索結果をページングして表示する |

各機能のサブセクションに記載する内容：

| フォームあり | フォームなし |
|---|---|
| 項目一覧 | 動作の説明のみ |
| バリデーション仕様 | |
| ボタン | |
| 処理フロー（複雑な場合のみ） | |

### 項目一覧

| # | 項目名 | 入力形式 | データ形式 | バリデーション | 備考 |
|---|---|---|---|---|---|
| 1 | 氏名 | テキスト | string | 必須 | |

入力形式の選択肢: テキスト / パスワード / 日付 / セレクトボックス / ラジオボタン / 単一チェックボックス / 複数チェックボックス / ファイルアップロード / テキストエリア / 表示のみ

### バリデーション仕様

- バリデーションライブラリ: zod + React Hook Form
- バリデーションタイミング: 保存ボタン押下時
- エラーメッセージ表示位置: 各フィールドの直下
- スキーマ定義: `shared/schemas/xxx.ts` の `xxxSchema`

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| 氏名 | 必須項目 | 氏名は必須項目です |

### ボタン

| ボタン名 | 動作 |
|---|---|
| 保存 | バリデーション後、API リクエストを送信する |
| キャンセル | 一覧画面へ遷移する |

### 処理フロー（フォーム送信）

複雑な処理がある場合のみ記載する。基本的なフォーム送信は以下を標準とする。

1. 保存ボタン押下時にバリデーションを実行する
2. バリデーションエラーがある場合はエラーメッセージを各フィールドに表示し中断する
3. バリデーション通過後、API リクエストを送信する
4. リクエスト中は全フィールドおよび全ボタンを disabled にする
5. 保存完了後、遷移先画面へ遷移する
6. 遷移先で Snackbar を表示する（`navigate(path, { state: { snackbar: { severity, message } } })`）
7. 保存失敗時はエラーメッセージをページ上部に表示し、disabled を解除して再入力を促す

---

## 状態管理

フックが管理する状態の一覧を記載する。

| 状態 | 型 | 説明 |
|---|---|---|
| `isSubmitting` | `boolean` | 送信中フラグ |
| `apiError` | `string \| null` | APIエラーメッセージ |

- ローカル変数（`const` で宣言し `useState` を使わないもの）は記載しない
- React Hook Form が管理するフォーム値は記載しない

---

## 更新ルール

- 画面・フックを変更したら以下を同時に更新する
  1. `docs/screens/_screen_list.md`（画面一覧への追記）
  2. 対応するテスト仕様書（`docs/tests/frontend/`）
- 新規画面を追加するときは `docs/screens/_template.md` をコピーして作成する
