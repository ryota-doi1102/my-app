# SignUpPage

## 概要

メールアドレスとパスワードを使った新規アカウント作成（サインアップ）画面。

## 機能

- メールアドレス入力フォーム
- パスワード入力フォーム（8文字以上・大文字・小文字・数字をそれぞれ1文字以上含む）
- パスワード確認フォーム（パスワードと一致するかバリデーション）
- サインアップボタン（フォーム送信）
- サインイン画面へのリンク（`/sign-in`）

## API フロー

1. `POST /api/v1/auth/signup/request` — メールアドレスでトークンを発行
2. `POST /api/v1/auth/signup` — トークン・メール・パスワードでアカウント作成
3. 成功後 `/sign-in` へリダイレクト

## ルート

`/sign-up`
