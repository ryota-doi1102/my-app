# ユーザープロフィール作成画面

新規ユーザーのプロフィール情報を入力・保存する画面。

## URL

`/users/create`

## ファイル構成

|----------|------|
| `index.tsx` | ページコンポーネント（UI） |
| `useUserCreateForm.ts` | フォームロジック（RHF + zod） |

## 年齢の自動計算仕様

- 生年月日が入力されると即時に年齢を計算して表示する
- 今日の日付を基準に満年齢を算出する
- 生年月日が未入力の場合は空欄とする

## ボタン

| ボタン名 | 動作 |
|----------|------|
| 保存 | バリデーション後、保存処理を実行する |
| キャンセル | ユーザー一覧画面へ遷移する（入力がある場合は確認ダイアログを表示） |

## 保存処理の仕様

1. 保存ボタン押下時にバリデーションを実行する
2. バリデーションエラーがある場合はエラーメッセージを各フィールドに表示し、処理を中断する
3. バリデーション通過後、API リクエストを送信する
4. リクエスト中は **全フィールドおよび全ボタンを disabled 状態** にして操作を不可とする
5. 保存完了後、ユーザー一覧画面（`/users/list`）へ遷移する
6. 遷移先で Snackbar を表示する（表示内容は画面遷移時の State で渡す）
   - 例: `{ severity: "success", message: "プロフィールを保存しました" }`
7. 保存失敗時はエラーメッセージをページ上部に表示し、disabled を解除して再入力を促す

## キャンセル処理の仕様

- いずれかの項目に入力がある場合、確認ダイアログを表示する
  - ダイアログ内容: 「入力内容が失われますが、よろしいですか？」
  - 「OK」押下 → ユーザー一覧画面へ遷移
  - 「キャンセル」押下 → ダイアログを閉じて入力を継続
- 全項目が未入力の場合は確認なしにユーザー一覧画面へ遷移する

> **注意**: ブラウザの戻るボタン・リロード・タブ閉じ等のブラウザネイティブ操作には確認ダイアログを表示しない（`beforeunload` 等は使用しない）

## バリデーション仕様

- バリデーションライブラリ: zod + React Hook Form
- バリデーションタイミング: 保存ボタン押下時（送信時のみ）
- エラーメッセージ表示位置: 各フィールドの直下
- スキーマ定義: `shared/schemas/user.ts` の `userProfileCreateSchema`

| フィールド | ルール | エラーメッセージ |
|------------|--------|------------------|
| 氏名 | 必須項目 | 氏名は必須項目です |
| 生年月日 | 必須項目 | 生年月日は必須項目です |

| プロフィール画像 | JPEG / PNG / WebP 形式のみ許可 | 対応していないファイル形式です |
| プロフィール画像 | 5MB 以下のみ許可 | ファイルサイズが上限を超えています |
| 電話番号 | 入力がある場合は10〜11桁の数字のみ許可 | 電話番号の形式が正しくありません |
| メールアドレス | 必須項目 | メールアドレスは必須項目です |
| メールアドレス | RFC 準拠のメール形式のみ許可 | メールアドレスはメールアドレス形式で入力してください |

| パスワード | 8文字以上のみ許可 | パスワードは8文字以上で入力してください |
| 郵便番号 | 入力がある場合は7桁の数字のみ許可 | 郵便番号の形式が正しくありません |
| 資格 | 入力がある各行は1文字以上 | 資格名は必須項目です |
